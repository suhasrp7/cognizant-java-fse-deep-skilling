# Hands-On 9: State Management using NgRx

## Objective
Implement state management in an Angular application using NgRx Store, Actions, Reducers, Effects, and Selectors. Manage course and enrollment state with Redux DevTools integration.

## Features
- NgRx Store Configuration
- Course State Management
- Actions and Reducers
- NgRx Effects for Async Operations
- Selectors with Memoization
- Enrollment Management
- Redux DevTools Integration

## Technologies Used
- Angular 20
- TypeScript
- NgRx Store
- NgRx Effects
- RxJS

## Installation

```bash
npm install
```

## Run the Application

```bash
ng serve
```

Open:

```
http://localhost:4200/
```
